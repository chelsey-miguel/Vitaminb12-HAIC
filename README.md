# Know Your District

HAIC 2026 entry for the DBEDT Know Your District

**Solution type:** ArcGIS Experience Builder with supporting embed pages

## Access
- **Map app (ArcGIS Experience Builder):** `(https://experience.arcgis.com/experience/3dca2a99468841739684895dc3c8f90d)`

## Modules, services and platforms used
**ArcGIS (Esri)**
- ArcGIS Online hosted feature layers: House districts (51) and Senate districts (25), with Census (ACS) indicator fields.
- ArcGIS Online web map with the district layers.
- ArcGIS Experience Builder app using the Map, Feature Info, Search, Text, Button and Embed widgets
